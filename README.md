# Appu's Garden

A free learning game for children aged 4–6 (UKG / KG-2). It runs in the browser, works on touch screens and with a stylus, and keeps working offline once installed.

- **Writing:** warm-up lines, letters a–z and A–Z, small words and number names, traced with stroke order on sky / grass / ground lines.
- **Listening:** first, middle and last sounds, rhymes, counting sounds, and spotting letters that look alike.
- **Reading:** short words, sentences and little stories.
- **Numbers:** reading, hearing and spelling the names of 1 to 100.

**Play:** open the GitHub Pages link of this repository in Chrome. On Android, choose **Install app** (or **Add to Home screen**) from the menu.

**Privacy:** there are no accounts, ads or tracking. The child's name and progress are saved only in that device's browser.
